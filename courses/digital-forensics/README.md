# 디지털 포렌식

4학년 1학기

디지털 증거, 저장장치, 문자·시간 표현, 파일 시그니처와 시스템 로그를 다룬 수업 및 과제 기록입니다.

같은 바이트라도 인코딩과 저장 방식에 따라 읽는 값이 달라집니다. 파일 종류는 확장자와 시그니처를 대조하고, 시각은 표기 형식·시간대와 어떤 사건을 기록한 값인지 확인합니다.

여러 기록을 시간순으로 놓을 때는 수집 경로와 원래 값을 함께 남깁니다. 조사에서 직접 확인한 기록, 기록을 연결해 얻은 해석, 더 확인해야 할 단서를 나눠야 다른 사람이 같은 근거를 다시 검토할 수 있습니다.
