# 생성형 인공지능 입문

4학년 2학기

생성형 AI 개요, 합성곱 신경망, 트랜스포머, StyleGAN, 영상 주석과 텍스트 기반 영상 생성 자료를 정리했습니다.

합성곱은 입력에서 가까운 영역의 특징을 보는 연산이고, 트랜스포머는 입력 요소 사이의 관계에 가중치를 줄 수 있습니다. 모델을 비교할 때는 어떤 정보를 입력받아 어떤 형태의 결과를 내는지부터 확인합니다.

영상에 주석을 다는 작업과 문장으로 영상을 생성하는 작업은 결과를 평가하는 기준이 다릅니다. 전자는 주석이 내용과 시점을 잘 설명하는지, 후자는 생성 결과가 주어진 조건과 맞는지 살핍니다.
