# 메모리 익스플로잇 해킹과 방어

4학년 1학기

프로세스의 메모리 구조, 스택 프레임, 메모리 오류, 실행 보호 기법을 방어 관점에서 정리했습니다.

메모리 접근이 가능한 범위와 입력의 길이가 일치하는지 확인합니다. 디버거에서 멈춘 위치를 볼 때는 그 지점의 값이 앞선 호출에서 어떻게 만들어졌는지 확인해야 최초 원인과 뒤늦게 나타난 증상을 구분할 수 있습니다.

NX, ASLR, SSP는 각각 메모리 실행 권한, 주소 배치, 스택 손상 감지를 다룹니다. 보완책을 설명할 때는 어느 조건을 완화하는지 적고, 코드에서 입력과 메모리 경계를 수정했는지도 따로 확인합니다.
