# C 프로그래밍

1학년

조건문, 반복문, 배열에서 시작해 포인터, 문자열, 구조체와 동적 할당으로 이어지는 실습 기록입니다.

배열을 넘기는 함수에는 길이도 함께 전달합니다. 문자열은 문자열의 길이와 종료 문자까지 포함한 버퍼 크기를 따로 확인해야 합니다. 구조체를 여러 개 다룰 때는 데이터를 어떻게 묶을지 먼저 정해야 반복문과 함수의 역할을 읽기 쉽습니다.

동적 할당은 사용할 크기, 할당 실패 처리, 해제 책임을 한 흐름에서 확인합니다. 입력이 0개일 때, 배열이 꽉 찼을 때, 문자열이 예상보다 길 때를 따로 확인하는 게 실습을 다시 볼 때의 기준입니다.
