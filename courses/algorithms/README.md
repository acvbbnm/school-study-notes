# 알고리즘

2학년 2학기·3학년 2학기

우선순위 큐, 힙, 정렬, 사전, 탐색 트리, 해시 테이블과 그래프를 공부했습니다. 퀵 정렬, 해시 테이블, 최단경로 실습도 이 범위에 있습니다.

정렬은 소요 시간과 추가 공간, 입력 분포에 따라 선택합니다. 퀵 정렬은 분할 결과가 한쪽으로 치우치는 입력을, 해시 테이블은 충돌이 생기거나 키가 몰리는 상황을 함께 확인합니다.

그래프 문제에서는 도달 가능성, 모든 정점의 연결 비용, 한 출발점에서의 이동 비용을 구분합니다. 방향과 가중치 조건을 확인한 뒤 순회, 최소신장트리, 최단경로 중 필요한 문제를 찾습니다.
