# 학교 정보보안·컴퓨터 학습 노트

대학에서 공부한 프로그래밍, 시스템, 정보보안 과목을 다시 볼 수 있게 정리했습니다. 과목별로 다룬 주제와 실습이나 프로젝트를 검토할 때 사용하는 기준을 담았습니다.

## 과목별 노트

| 과목 | 학기 | 다룬 내용 |
|---|---|---|
| [C 프로그래밍](courses/c-programming/README.md) | 1학년 | 조건문, 반복문, 배열에서 시작해 포인터, 문자열, 구조체와 동적 할당으로 이어지는 실습 기록입니다. |
| [정수론과 암호의 기초](courses/number-theory/README.md) | 1학년 | 정수, 최대공약수, 소수, 합동을 암호 알고리즘을 읽는 데 필요한 연산으로 정리했습니다. |
| [이산수학 및 프로그래밍](courses/discrete-math/README.md) | 2학년 1학기 | 논리와 명제, 집합, 관계, 증명법을 정리했습니다. |
| [자료구조](courses/data-structures/README.md) | 2학년 1학기 | 실행 비용, 재귀, 연결 리스트, 큐와 트리를 공부한 기록입니다. |
| [컴퓨터 네트워크](courses/computer-networks/README.md) | 2학년 1학기 | 보관된 네트워크 중간 학습 자료를 다시 읽을 때의 기준입니다. |
| [보안 프로그래밍](courses/secure-programming/README.md) | 2학년 2학기 | C와 C++ 코드에서 입력, 산술, 메모리 조건을 확인하는 순서를 정리했습니다. |
| [알고리즘](courses/algorithms/README.md) | 2학년 2학기·3학년 2학기 | 우선순위 큐, 힙, 정렬, 사전, 탐색 트리, 해시 테이블과 그래프를 공부했습니다. 퀵 정렬, 해시 테이블, 최단경로 실습도 이 범위에 있습니다. |
| [어셈블리어](courses/assembly/README.md) | 2학년 2학기 | 데이터 표현, IA-32 구조, 명령어와 주소 지정 방식을 다뤘습니다. |
| [컴퓨터 구조](courses/computer-architecture/README.md) | 2학년 2학기 | 컴퓨터 시스템의 구성과 CPU의 역할을 공부한 기록입니다. |
| [데이터베이스 보안](courses/database-security/README.md) | 3학년 1학기 | 남아 있는 수업 자료는 데이터베이스 최적화에 관한 부분입니다. |
| [운영체제 및 보안](courses/os-security/README.md) | 3학년 1학기 | 운영체제 개론 자료를 바탕으로 프로그램이 시스템 자원을 사용하는 경계를 정리했습니다. |
| [정보보호 연구입문](courses/security-research/README.md) | 3학년 1학기 | 전파 모델과 온디바이스 AI 환경의 보안·ID 관리 자료를 살펴봤습니다. |
| [AI 기반 시스템 프로그래밍](courses/ai-systems-programming/README.md) | 3학년 2학기 | 개발 환경 구성과 AI Assist Shell 과제를 바탕으로 시스템 도구의 실행 흐름을 봤습니다. |
| [사이버윤리와 프라이버시](courses/cyber-ethics/README.md) | 3학년 2학기 | 사이버 공간의 익명성, 표현의 자유, 개인정보 침해 사례를 정보보호 관점에서 정리했습니다. |
| [선형대수의 컴퓨팅 기초](courses/linear-algebra/README.md) | 3학년 2학기 | 행렬, 역행렬, 벡터, 연립방정식과 가우스-조단 소거 실습을 다뤘습니다. |
| [시스템보안](courses/system-security/README.md) | 3학년 2학기 | 운영체제와 x86 실행 구조, 계정·권한, 경쟁 조건과 메모리 취약점의 원인을 다뤘습니다. |
| [디지털 포렌식](courses/digital-forensics/README.md) | 4학년 1학기 | 디지털 증거, 저장장치, 문자·시간 표현, 파일 시그니처와 시스템 로그를 다룬 수업 및 과제 기록입니다. |
| [메모리 익스플로잇 해킹과 방어](courses/memory-security/README.md) | 4학년 1학기 | 프로세스의 메모리 구조, 스택 프레임, 메모리 오류, 실행 보호 기법을 방어 관점에서 정리했습니다. |
| [정보보호캡스톤디자인 · AI Sherpa](courses/security-capstone/README.md) | 4학년 1학기 | NCP와 NHN Cloud에서 무엇을 수집하고 어떤 근거로 사고를 판단할지 정리하는 4인 팀 프로젝트입니다. 팀장을 맡았습니다. |
| [생성형 인공지능 입문](courses/generative-ai/README.md) | 4학년 2학기 | 생성형 AI 개요, 합성곱 신경망, 트랜스포머, StyleGAN, 영상 주석과 텍스트 기반 영상 생성 자료를 정리했습니다. |

수업 교안, 시험·과제 원본, 실습 이미지와 제출 파일은 개인 아카이브에 보관합니다.

과정 밖에서 진행한 보안 실습은 [SeSAC 학습 노트](https://github.com/acvbbnm/sesac-study-notes)에 모았습니다.
